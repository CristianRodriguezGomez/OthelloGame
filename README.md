
# OthelloGame

OthelloGameCris es una implementación del clásico juego de mesa Othello (Reversi) en Python, con una interfaz gráfica creada con Tkinter y una inteligencia artificial con tres niveles de dificultad.

## 📌 Características
- Interfaz gráfica intuitiva con Tkinter.
- IA con tres niveles de dificultad: Principiante, Intermedio y Avanzado.
- Posibilidad de jugar como negras o blancas contra la IA.
- Sistema de validación de movimientos y conteo de fichas.
- Reinicio del juego y detección automática del ganador.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** Python
- **Bibliotecas:** Tkinter, Enum, Random

## 🎮 Cómo jugar
1. Selecciona si quieres jugar con las fichas negras o blancas.
2. Ingresa tu nombre.
3. Elige la dificultad de la IA (Principiante, Intermedio o Avanzado).
4. Haz clic en el tablero para colocar tus fichas según las reglas de Othello.
5. ¡Gana atrapando la mayor cantidad de fichas del oponente!

## 🧠 Niveles de dificultad de la IA
- **Principiante:** Movimientos aleatorios.
- **Intermedio:** Evita ciertas posiciones estratégicamente desventajosas.
- **Avanzado:** Prioriza las esquinas y realiza movimientos más estratégicos.

## 📌 Archivos principales
- `main.py` → Contiene la interfaz gráfica con Tkinter.
- `game_logic.py` → Implementa la lógica del juego y la IA.

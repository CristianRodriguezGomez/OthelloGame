OthelloGameCris
Descripción
OthelloGameCris es una implementación del juego de Othello (Reversi) con una interfaz gráfica creada en Python usando la biblioteca Tkinter. Los jugadores pueden elegir entre dos colores de fichas (Negro o Blanco) y enfrentarse contra una IA con distintos niveles de dificultad (principiante, intermedio y avanzado).

Características:
Interfaz gráfica con Tkinter.
El jugador puede elegir el color de sus fichas y su nombre.
Tres niveles de dificultad para jugar contra la IA: Principiante, Intermedio, y Avanzado.
El juego muestra el estado del tablero y el turno actual.
Al finalizar el juego, se muestra el ganador o si hay empate.
Requisitos:
Python 3.x
Tkinter (normalmente ya está incluido en Python)
